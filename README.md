# 🏠 Emlak & Airbnb Fotoğraf İyileştirme

> 🔒 **Bu proje ticari olarak geliştirilmektedir — kaynak kodu kapalıdır.** Demo veya detaylı bilgi için [iletişime geçebilirsiniz](#-i̇letişim).

Emlak ilanları ve Airbnb listeleri için fotoğrafları otomatik iyileştiren yapay zekâ destekli araç. Sıradan telefon fotoğraflarını profesyonel ilan fotoğrafı kalitesine yaklaştırır.

## ✨ Özellikler

- **Otomatik fotoğraf iyileştirme** — ışık, renk ve netlik düzeltmeleri
- **Sinematik stil** — ilan videoları/reels için sinematik görünüm profili
- **Güvenli işleme limitleri** — toplu işlemde kaynak koruması
- **Web arayüzü** — sürükle-bırak ile kolay kullanım
- **Toplu işleme** — tüm ilan fotoğraflarını tek seferde iyileştirme

## 🎯 Kimin İçin?

- Emlak ofisleri ve danışmanlar
- Airbnb / kısa dönem kiralama ev sahipleri
- İlan fotoğrafçılığına bütçe ayıramayan bireysel satıcılar
